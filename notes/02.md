# 1. Potenciacao

Potenciacao e uma operacao matematica que representa a multiplicacao de um numero por ele mesmo repetidamente.

Por exemplo:

2^3 = 2 * 2 * 2 = 8

Temos tres elementos:

- Base: 2
- Expoente: 3
- Resultado: 8

# 1.1 Propriedades da potenciacao

Existem algumas propriedades que voce precisa conhecer.

## Propriedade 1 - Multiplicacao de potencias com a mesma base

Quando multiplicamos potencias com a mesma base, somamos os expoentes.

a^m * a^n = a^m+n

## Propriedade 2 - Divisao de potencias com a mesma base

Subtraimos os expoentes.

a^m / a^n = a^m-n

## Propriedade 3 - Potencia de potencia

Multiplicamos os expoentes.

(a^m)^n = a^m*n

## Propriedade 4 - Expoente zero

Todo numero diferente de zero elevado a zero e igual a 1.

## Propriedade 5 - Expoente negativo

Um expoente negativo representa o inverso da potencia positiva.

a^-n = 1 / a^n

# 1.2 Implementacao em Python

Python possui o operador ** para potenciacao.

```python
print(2 ** 3) # 8
```

Tambem podemos utilizar a funcao `pow()`:

result = pow(2,3)

print(result) # 8

Uma observacao em Python, `^` nao representa potenciacao. Ele representa XOR bit a bit.

# 2. Raizes matematicas

A raiz e a operacao inversa da potenciacao.

Por exemplo:

5^2 = 25

Portanto:

Raiz quadrado de 25 = 5

A raiz quadrada procura um numero que, multiplicado por ele mesmo, produz o valor original.

# 2.1 Relacao entre raizes e expoentes

Existe uma propriedade muito importante:

Raiz quadrado de x = x elevado a 1/2

E, de maneira mais geral:

Raiz ao n de x = x elevado a 1/n

Exemplo:

Raiz ao cubo de 27 = 27 elevado a 1/3 = 3

Essa relacao sera muito util quando comercamos a trabalhar com formulas estatisticas.

# 2.2 Implementacao em Python

```python

import math

print(math.sqrt(25)) # 5.0

```

Tambem podemos calcular raizes utilizando potenciacao:

```python

result = 27 ** (1/3)

print(result)

```

Entretanto, para raizes quadradas, prefira `math.sqrt()` pela clareza da intencao.

# 2.3 Onde isso aparece em Estatistica?

Aqui chegamos a uma aplicacao muito importante.

Lembra que mencionamos variancia e desvio padrao na primeira aula?

O desvio padrao e calculado utilizando uma raiz quadrada.

A formula da variancia populacional e:

\[
\sigma^2 = \frac{\sum_{i=1}^{N}(x_i-\mu)^2}{N}
\]

E o desvio padrao:

\[
\sigma = \sqrt{\sigma^2}
\]

Nao se preocupe em memorizar essa formula agora. Vamos estuda-la em profundidade em modulo de estatistica descritiva.

Por enquanto, quero que perceba duas coisas:

1. Elevamos as diferencas ao quadrado.
2. Depois calculamos a raiz quadrada da variancia.

Exemplo simplificado:

Imagine os valores [2, 4, 6]

A media e = 2 + 4 + 6 / 3 = 4

Diferencas em relacao a media = [-2, 0, 2]

Elevando ao quadrado = [4, 0, 4]

Variancia populacional = 4 + 0 + 4 / 3 = 2.6667

Desvio padrao = sqrt(2.6667) ~= 1.633

Esse e um dos motivos pelos quais estamos estudando potenciacao e raizes antes de entrar na estatistica propriamente dita.

# 3. Logaritmos

Agora vamos para um conceito que costuma parecer mais dificil inicialmente, mas que possui aplicacoes muito interessantes. 

Um logaritmo e a operacao inversa da potenciacao.

Imagine: 2^3 = 8

Podemos perguntar:

"Qual expoente precisamos aplicar ao numero 2 para obter 8?"

A resposta e 3.

Representamos isso como: 

log2(8) = 3

Os elementos sao:

- Base: 2
- Resultado da operacao: 8
- Expoente encontrado: 3

Formalmente:

logb(x) = y

b^y = x

# 3.1 Tipos de logaritmos

Existem tres tipos que voce encontra frequentemente:

Logaritmo binario onde a base e 2 log2(x)

Logaritmo decimal onde a base e 10 log10(x)

Logaritmo natural onde a base e 'e' ln(x)

O numero 'e' e uma constante matematica aproximadamente igual a 2.71828

O logaritmo natural aparece bastante em estatistica, probabilidade, distribuicao e Machine Learning.

# 3.2 Propriedades importantes

Multiplicacao:

logb(xy) = logb(x) + logb(y)

Divisao:

logb(x / y) = logb(x) - logb(y)

Potenciacao:

logb(x^n) = n * logb(x)

Nao precisamos decorar todas agora, mas e importante compreender como os logaritmos simplificam operacoes matematicas.

# 3.3 Implementacao em Python

Utilizando `math`:

```python

import math

print(math.log2(8)) # 3.0

```

A funcao `math.log()` utiliza logaritmo natural por padrao.

Tambem podemos especificar uma base:

```python

result = math.log(16, 2)

print(result) # 4.0

```

Atencao: logaritmos reais exigem argumento positivo e uma base positiva diferente de 1.

Por exemplo, `math.log(0)` e `math.log(-5)` geram erros de dominio matematico.

# 3.4 Aplicacao em computacao e estatistica

Existem varias aplicacoes.

*Complexidade de algoritmos*

Voce provavelmente ja encontrou a notacao O(logn).

Algoritmos como Binary search possuem complexidade logaritmica.

Imagine procurar um elemento em uma lista ordenada de 1024 elementos.

Na busca binaria, o espaco de busca e reduzido pela metade a cada operacao:

log2(1024) = 10

Sao necessarias aproximadamente 10 divisoes do espaco para busca para chegar a um unico elemento.

*Machine Learning*

Logaritmos aparecem em funcoes de perda, como Log Loss, e na entropia utilizada em teoria da informacao.

*Probabilidade*

Distribuicoes exponenciais e calculos envolvendo probabilidades muito pequenas tambem podem utilizar transformacoes logaritmicas.

# 4. Notacao cientifica

Agora vamos aprender a representar numeros muito grandes ou muito pequenos de maneira compacta.

A notacao cientifica utiliza a seguinte estrutura:

a * 10^n

Onde:

- a e um numero entre 1 e 10 em valor absoluto.
- n e um numero inteiro.

Exemplos:

1000 = 1 * 10^3

1_000_000 = 1 * 10^6

0.001 = 1 * 10^-3

# 4.1 Porque isso e importante?

Em computacao e estatistica, podemos encontrar numeros extremamente grandes ou pequenos.

Imagine:

- Quantidade de combinacoes possiveis.
- Probabilidade muito pequenas.
- Valores de precisao numerica.
- Quantidades de eventos em grandes populacoes.
- Dados cientificos.

A notacao cientifica torna esses valores mais faceis de interpretar.

# 4.2 Implementacao em Python

```python

large_number = 1e6
small_number = 1e-7

print(large_number) # 1000000.0
print(small_number) # 1e-07

```

Tambem podemos formatar:

```python

value = 0.000000123

print(f"{value:.2e}") # 1.23e-07

```

Uma observacao importante: computadores trabalham com precisao finita. Isso significa que alguns numeros decimais nao podem ser repersentados exatamente em ponto flutuante.

Por exemplo:

```python
print(0.1 + 0.2) # 0.30000000000000004
```

Isso nao e um erro da matematica nem necessariamente um bug do Python. E uma caracteristica da representacao numerica em ponto flutuante.

Vamos aprofundar esse assunto quando estudarmos precisao numerica e calculos estatisticos.
